# Sirius

Sirius is a shogi engine framework, written by F#.

Shogi is game like chess.

## Source Code Explanation

(1) AttacksOperation.fs : Functions of piece attacks.

(2) BitOperation.fs : Functions of bit operations.

(3) Board.fs : Functions of shogi board.

(4) Common.fs : Common constants and variables.

(5) CSA.fs : Functions of CSA format.

(6) Evaluate.fs : Evaluation Functions.

(7) Feature.fs : Constants and variables for feature vector.

(8) GenMoves.fs : Functions for generating moves.

(9) IO.fs : Functions for reading records.

(10) Mate1Ply.fs : Function for mate in one ply.

(11) Move.fs : Functions for moves.

(12) Program.fs: The entry point of this software.

(13) SFEN.fs : Functions for SFEN.

(14) Sort.fs : Functions for sorting moves.

(15) Test.fs : Functions for testing.
